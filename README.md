Python-Task3-RandomPasswordGenerator
DESCRIPTION:-

The Random Password Generator is a desktop application built with tkinter or PyQt5 that creates cryptographically secure passwords using Python's secrets module based on user-defined constraints. It features sliders or spinboxes for setting password length (minimum 8 characters) and checkboxes to select character sets—such as uppercase, lowercase, numbers, and symbols—enforcing a minimum selection of two types and ensuring at least one character from each selected set is included. The application provides robust input validation, a visual password strength indicator (Weak, Medium, Strong), an option to filter out ambiguous characters (like 0, O, l, 1), automatic clipboard copying via pyperclip, and a session history tracking the last five generated passwords without saving them to disk.
